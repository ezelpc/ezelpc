# Security Policy

## Scope

This profile and its public repositories are primarily portfolio, educational and authorized security-engineering projects.

## Reporting

If you identify a security issue in one of the projects, please avoid publishing sensitive details in a public issue. Use GitHub's private vulnerability reporting when available or contact me through the email listed on my profile.

## Responsible use

Security tooling and attack simulations in these repositories are intended for systems the user owns or is explicitly authorized to test.

Never commit credentials, API keys, private certificates, tokens, production data or other sensitive information.
